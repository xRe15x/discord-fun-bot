# discord-fun-bot

Discord bot made by using [discord.js](https://discord.js.org/) and typescript, focusing on fun commands. This is my second discord bot (though you could say it's my first if you exclude the bot I made from following the [guide](https://discordjs.guide/legacy)).

Typescript might be a bit wack mostly because I couldn't find a good resource for discord.js with typescript (Documentation does exist but that's only helpful if I know what I'm looking for)

If I ever feel like it then maybe in the future I will make a "v2" of this bot with more and better commands that will make someone actually consider using it.

## Commands

I might occasionally add more commands in the future.

fun

- `/coinflip` - Flip a coin
- `/fact` - Get a random fact
- `/8ball` - Ask the magic 8 ball a question

games

- `/hangman` - Play hangman
- `/higher_or_lower` - Guess a number
- `/rps` - Rock Paper Scissors
- `/truth_or_dare` - Play truth or dare

utility

- `/commands` - List all commands
- `/ping` - Check if the bot is online

## AI Usage

I **have** used AI to create most of the responses for truth or dare and the fact command. **I do utilise AI to help me learn** but **not** to generate code for me.
